# Linux Landing Page 🐧

Welcome to my **Linux Landing Page** project! This is a responsive web page built from scratch as part of **The Odin Project** curriculum (Foundations Path). 

Instead of using ordinary placeholder text, I decided to dedicate this project to explaining **Why Developers Should Switch to Linux**, specifically focusing on the open-source philosophy and the power of the Fedora ecosystem.

---

## 🚀 Purpose of the Project
The main goal of this assignment is to master **CSS Flexbox** layouts, practice semantic HTML structure, and build a clean, modern web user interface without relying on external CSS frameworks.

## 🛠️ Technologies Used
* **HTML5:** For creating a semantic, structured document.
* **CSS3:** For custom styling, layout control, and positioning using **Flexbox**.
* **Git & GitHub:** For version control and project deployment.

## 🎯 Key Features of the Design
* **Hero Section:** An engaging introduction to the power of Linux with a call-to-action button.
* **Features Matrix:** A 4-card flexible layout showcasing the core advantages of Linux (Open Source, Package Managers, Performance, and Security).
* **Quotes Section:** Featuring an inspiring quote from Linus Torvalds.
* **Call-to-Action (CTA):** A clean section urging users to download and try Fedora Linux.
